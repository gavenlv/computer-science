## D-001 · 10 个方向全做

### 结论

保留 10 个专业方向：

1. 人工智能
2. 网络通信
3. 大数据
4. 网络安全
5. 云计算
6. 图形学与游戏
7. 嵌入式与 IoT
8. 软件架构
9. 人机交互
10. 量子计算与前沿

### 为什么

- 用户明确要求「每一个领域都专业」；
- 10 个方向覆盖了 CS2023 的应用侧与当前产业的主要分支；
- 课程库可以先建目录与标准，再按需求排产，不必二选一；
- 方向之间大量复用核心课（数学、系统、算法、分布式、安全），边际成本递减。

### 代价

- 全量内容量约 3,000 课时，一个人全原创需要 20+ 年；
- 必须坚持「先核心、后方向」，否则会出现「10 个方向都只有大纲」；
- 方向建设要有明确顺序，不能平均用力。

## D-002 · 先完成计算机基础

### 「计算机基础」指什么

不是「4 门基础课」，而是**核心学院的 23 门课 / 165 模块 / 811 课时**。
为了可执行，拆成两批：

#### Core v1（首发核心，15 门 / 555 课时）

| 组 | 课程 | 课时 |
| --- | --- | ---: |
| 启程 | F00 计算机如何思考、F01 Python、F02 工具链、F03 数学预备 | 100 |
| 编程与算法 | C01 程序设计进阶、C02 C 与系统编程、C03 算法 I | 115 |
| 数学 | M01 离散数学、M02 线性代数、M03 概率统计 | 100 |
| 系统 | S01 计算机组成、S02 操作系统、S03 计算机网络、S04 数据库 | 200 |
| 工程 | E01 软件工程 | 40 |
| **合计** | **15 门** | **555** |

> Core v1 的目标：一个零基础学习者能写程序、懂数学、懂系统、能抓包、能建库、能做小项目。

#### Core v2（完整核心，8 门 / 256 课时）

| 课程 | 课时 |
| --- | ---: |
| C04 数据结构与算法 II | 40 |
| M04 微积分与最优化 | 30 |
| S05 并行与分布式系统 | 40 |
| S06 编译原理 | 40 |
| S07 计算理论 | 30 |
| S08 安全基础 | 30 |
| E02 系统设计 | 30 |
| E03 技术写作与协作 | 16 |
| **合计** | **256** |

> Core v1 + Core v2 = 23 门 / 811 课时。**Core v2 完成前，不全面推进其余 9 个方向。**

### 例外：网络旗舰可以提前

网络既是核心课 S03，也是第一旗舰方向。允许在核心阶段提前做：

- S03 的完整课时与实验（核心课）；
- N01「实现 TCP/IP」与 N03「网络性能与排障」的部分模块（方向课），作为教学法试验；
- 其余 N 方向课程在核心完成后再补。

这不违背「先核心」，因为网络旗舰本身就是核心课 S03 的垂直切片。

## D-003 · 第一旗舰课：计算机网络

### 结论

第一门按「完整内容标准」生产的旗舰课是 **S03 计算机网络**，配套 N01/N03 的深化模块。

### 为什么是网络

| 理由 | 说明 |
| --- | --- |
| 用户明确要求 | 「要知道底层通信原理，如何应用」 |
| 可视化强 | 数据包、状态机、时序图、拓扑、拥塞曲线 |
| 交互强 | 抓包回放、参数滑块、单步协议、路由模拟 |
| 可验证 | 每个实验都有真实输出（Wireshark/curl/ss/tcpdump） |
| 差异化 | 「能抓包 + 能实现 + 能排障」的网络课稀缺 |
| 复用现有 | `fundamentals` 中的网络模块可作为种子 |

### 旗舰范围（第一版）

- S03 全部 10 模块 / 50 课时；
- N01 的 TCP receiver/sender 实验（可裁剪）；
- N03 的抓包/排障/拥塞对比实验；
- 5 个可复用组件：协议时序、状态机、抓包回放、参数曲线、拓扑/路由；
- 1 个 P2 项目：TCP 子集 + HTTP 服务器，或网络测量报告。

### 不做什么

- 不先做完整 N02–N07；
- 不做「网络设备配置大全」；
- 不做与核心无关的厂商认证题库。

## D-004 · 「硕士级」= 能力等效，不授学位

### 统一表述

对外与课程内统一使用：

> **「硕士等效能力」**：完成方向 L4–L5 的课程、论文复现、原创项目与答辩，
> 达到「能读研/能进研究型团队/能独立做方向项目」的能力水平。
> 本体系不授予学位，也不替代真实研究生院的导师指导与学术认证。

### 能力证据（每个方向 L5）

1. 读完 3–5 篇该方向顶会/顶刊论文，写出结构化笔记；
2. 复现 1 篇论文的 baseline，结果与论文同量级；
3. 完成 1 个原创扩展（消融/改进/新场景），解释有效或无效；
4. 写 15–30 页技术报告，代码/数据/实验可复现；
5. 通过 20 分钟答辩，能回答「为什么不用另一种方法」「局限是什么」。

### 禁止表述

- 「读完就是硕士」；
- 「包就业/包论文」；
- 「3 个月达到专家」；
- 用「课时数」直接等价「学位」。

## D-005 · 单人 + AI + 外部审校

### 结论

**1 人 + AI 辅助 + 外部学科审校**。

- 你：课程主编 + 技术作者 + 教学设计师 + 部分前端/可视化；
- AI：草稿、代码初稿、变体题、图初稿、翻译；
- 外部：每门课 1 位学科审校（按课时/按门课付费）；
- 社区：第 2–3 年再考虑，不作为早期依赖。

### 时间尺度（按 12–15 节/月）

| 里程碑 | 时间 |
| --- | ---: |
| Core v1（15 门 / 555 课时） | 4–5 年 |
| 核心 + 网络方向（1,051 课时） | 6–8 年 |
| 核心 + 网络 + AI（1,341 课时） | 9–10 年 |
| 10 个方向（2,931 课时，分层内容） | 14–16 年 |
| 10 个方向（全部原创旗舰） | 20–30 年 |

### 影响

- **09 文档是「3–4 人加速版」**，不作为单人的主排期；
- 单人主排期以 **11 文档** 为准；
- 第一年目标从 230 课时下调到 **100–130 课时**；
- 必须采用分层内容（D-006），否则 10 个方向无法在可接受时间内完成。

## D-006 · 分层内容模型（已确认）

> 2026-10-25 确认：接受 A 方案（分层内容）。
> 核心 + 网络 + AI 原创；数据/安全/云精编；图形/嵌入式/架构/HCI/量子导读。

| 层 | 范围 | 课时 | 生产方式 |
| --- | --- | ---: | --- |
| A 原创旗舰 | 核心 23 门 + 网络 7 门 + AI 8 门 | 1,341 | 自己写正文/图/实验/题 |
| B 精编 | 数据 7 + 安全 7 + 云 7 | 720 | 选公开教材/课程 + 原创实验/测评/项目 |
| C 导读 | 图形 6 + 嵌入式 6 + 架构 6 + HCI 5 + 量子 4 | 870 | 论文/书/公开课导读 + 项目 + 评审 |

### 为什么

- 一个人全原创 3,000 课时需要 20–30 年；
- 「专业」不等于每句话自己写，而是「选对材料 + 设计对实验 + 给对反馈 + 达到对标准」；
- 核心 + 网络 + AI 是最能形成差异化的部分，必须原创；
- 数据/安全/云/图形等已有大量优质公开材料，精编/导读的边际成本更低。

### 前提

- 精编/导读必须有：选材说明、导读、原创实验、原创测评、项目、审校；
- 不是「放链接」，也不是「复制教材」；
- 版权/来源合规；
- 学习效果用项目/测评验证，不靠「原创字数」。
