# 06 · 网站信息架构

> 目标：让学习者「3 次点击内到达任何一节课」，同时让「我不知道下一步学什么」这个问题消失。
>
> 现有站点是「板块 → 模块 → 课时」的目录型结构；新站点是「目标 → 路径 → 课程 → 课时 → 实验/测评」
> 的学习型结构，底层由知识图谱驱动。

---

## 1. 设计原则

1. **继续学习永远在第一屏**：首页最显眼的是「继续学习 / 今日复习」，不是营销文案。
2. **先给路径，再给目录**：新用户先选目标/做诊断，而不是面对 86 门课的列表。
3. **先修可见但可挑战**：显示「需要先学 X」，同时提供「我学过，测试跳过」。
4. **每节课都能动手**：课时页右侧/下方永远有实验入口，不需要跳转去找。
5. **进度 ≠ 看完**：进度由「掌握度」驱动（测验 + 实验 + 项目），不是滚动到底。
6. **移动端优先**：通勤/碎片时间可以看课、做题、复习；重实验引导到桌面。
7. **搜索覆盖一切**：课程、模块、课时、知识点、术语、论文、实验。
8. **深链接稳定**：课程/课时 ID 不随目录调整而失效，旧链接 301 到新地址。

## 2. 全局导航

### 2.1 顶栏（桌面）

```
[Logo]  学习地图   课程   实验室   项目   复习   论文        [搜索]   [我的]
```

- **学习地图**：知识图谱 + 路径入口；
- **课程**：课程库（按学院/方向/阶段/难度筛选）；
- **实验室**：代码/网络/SQL/终端实验；
- **项目**：P0–P5 项目库、Rubric、提交；
- **复习**：今日复习、错题、间隔卡；
- **论文**：L5 论文导读与复现任务；
- **搜索**：全局搜索（⌘/Ctrl+K）；
- **我的**：进度、能力雷达、笔记、证书/作品集。

### 2.2 移动端

底部 Tab：`首页 · 地图 · 复习 · 我的`，其余收进「更多」。
课时页采用「正文 / 实验 / 练习」三 Tab，避免横向三栏。

### 2.3 面包屑

```
学习地图 / AI 方向 / A02 深度学习 / 反向传播 / 计算图
```

每一级可点击；移动端只显示最后两级 + 返回。

## 4. 关键页面规格

### 4.1 首页 `/`

**目标**：30 秒内让用户知道「我从哪开始、下一步做什么」。

**模块**：

1. **继续学习卡**：上次课时、进度、预计剩余时间、[继续]；
2. **今日复习卡**：待复习卡片数、预计 10 分钟、[开始复习]；
3. **路径选择**：我是高中生 / 大学生 / 转行者 / 研究生（4 个入口）；
4. **知识地图缩略**：6 阶 + 10 方向的简化图，可点击；
5. **今日一课**：一个 5 分钟的概念/现象，降低启动成本；
6. **数据/信任**：多少课时、多少实验、多少项目（真实数字，不夸大）。

**不做**：大段营销文案、轮播图、课程堆砌。

### 4.2 入学诊断 `/start`

**流程**：

```
选画像 → 选目标（补齐基础/转行/考研/兴趣） → 诊断（20–40 min）
→ 结果页（已掌握/建议补/可直接学） → 生成路径 → 第一课
```

**诊断设计**：

- 自适应：答对升级，答错降级；
- 覆盖编程、数学、系统、方向；
- 每题有「不会」选项，不强迫猜；
- 结果不是分数，而是「能力雷达 + 最短路径」；
- 允许跳过诊断，直接选路径。

### 4.3 知识地图 `/map`

**两种视图**：

- **全景图**：6 阶为纵轴，课程为节点，先修关系为边；可缩放/拖拽；
- **列表视图**：按阶段/方向/课程分组，适合移动端与搜索。

**节点状态**：

| 状态 | 含义 | 视觉 |
| --- | --- | --- |
| 未开始 | 无进度 | 灰色描边 |
| 可开始 | 先修已满足 | 实色 |
| 学习中 | 有进度 | 进度环 |
| 已掌握 | 测验/项目通过 | 勾选/金色 |
| 锁定 | 先修未满足 | 锁 + 「需要先学 X」 |

**交互**：

- 点击节点 → 侧栏：目标、先修、课时数、预计时间、[开始/继续]；
- 悬停边 → 显示「为什么需要先修」；
- 筛选：阶段、方向、时长、是否有实验、是否可跳级；
- 「生成我的路径」：基于诊断/已学课程高亮最短路径。

### 4.4 课程库 `/courses`

**筛选维度**：

- 学院/方向（核心、AI、网络、数据、安全、云、图形、嵌入式、架构、HCI、量子）；
- 阶段（L0–L5）；
- 时长（<5h、5–15h、15–30h、>30h）；
- 形式（有实验、有项目、有论文）；
- 先修（无、需编程、需数学、需系统）；
- 状态（未开始、学习中、已完成）。

**卡片信息**：课程名、一句话目标、阶段、模块/课时、先修、进度、[开始]。

### 4.5 课程页 `/courses/:courseId`

**结构**：

1. **头图/摘要**：课程名、一句话、阶段、预计时长、先修、出口能力；
2. **学完能做什么**：3–5 条可验收能力；
3. **模块列表**：每模块的目标、课时数、实验、测验、状态；
4. **结课项目**：要求、Rubric、示例；
5. **学习建议**：先修/并行/跳过策略；
6. **评价/笔记**（后期）。

**关键组件**：

- 先修图（mini）；
- 「我学过，测试跳过」；
- 「预计 6 周，每周 5 小时」；
- 「本课在路径中的位置」。

### 4.6 模块页 `/courses/:courseId/:moduleId`

- 模块目标（1 句话）；
- 课时列表（标题、时长、类型、状态）；
- 模块实验（1 个 Lab）；
- 模块测验（10–20 题）；
- 项目里程碑；
- 上下模块导航。

### 4.7 课时页 `/lessons/:lessonId`

**桌面三栏**：

```
┌──────────────┬──────────────────────────────────────┬─────────────────┐
│ 本课目录      │  正文（图/动画/代码/交互）             │  实验/术语/笔记   │
│ 00 问题      │                                      │  [运行代码]      │
│ 01 先猜      │   ...                                │  [术语卡]        │
│ 02 机制      │                                      │  [我的笔记]      │
│ ...          │                                      │  [提问]          │
└──────────────┴──────────────────────────────────────┴─────────────────┘
```

**移动端**：正文 + 底部 Tab（实验/练习/笔记）；图可全屏。

**必须有的元素**：

- 顶部：课程/模块/课时、预计时长、难度、完成状态；
- 正文：10 个块（见 05 文档）；
- 右侧/下方：可运行实验、术语、笔记、提问；
- 底部：上一课/下一课、[标记掌握]（通过测验后自动）。

**学习状态**：

- 阅读进度（滚动）；
- 检查点（每 6–8 分钟）；
- 实验完成；
- 练习得分；
- 只有「测验 ≥ 80 + 实验完成」才标记掌握。

### 4.8 实验室 `/labs`

**类型**：

| 类型 | 能力 | 示例 |
| --- | --- | --- |
| Python 沙箱 | 运行/测试/绘图 | 算法、数据处理 |
| C/C++ 沙箱 | 编译/运行/ASan | 指针、内存、系统 |
| SQL 沙箱 | 建表/查询/执行计划 | 数据库、数据分析 |
| 终端 | 模拟 Linux 命令 | 工具链、OS |
| 网络 | 抓包/协议回放/拓扑 | TCP、HTTP、路由 |
| GPU/模型（后期） | 远程 notebook | 深度学习 |

**实验页结构**：目标 → 环境 → 初始代码 → 步骤 → 预期输出 → 改一改 → 排查 → 提交。

### 4.9 项目库 `/projects`

- 按 P0–P5、方向、难度、时长筛选；
- 项目卡：目标、技能、交付物、Rubric 摘要、示例；
- 项目详情：背景、需求、里程碑、Rubric、提交、展示墙；
- 支持「团队项目」（后期）。

### 4.10 复习 `/review`

- **今日复习**：卡片数、预计时间、[开始]；
- **错题本**：按课程/知识点分组；
- **间隔队列**：1/3/7/21 天；
- **掌握度**：按知识点显示雷达/热力图；
- **复习形式**：选择题、填空、解释题、代码微任务。

### 4.11 论文 `/papers`

- 按方向/难度/年份筛选；
- 论文卡：标题、作者/会议、一句话贡献、前置课程、复现难度；
- 论文页：导读（问题/方法/实验/局限）、关键图、复现任务、讨论题；
- 「读论文」不是「看摘要」：要求写 5 条笔记 + 1 个问题。

### 4.12 我的 `/me`

- **能力雷达**：按 CS2023 知识领域/方向；
- **学习记录**：课程、课时、实验、项目、论文；
- **作品集**：项目卡 + 链接 + 演示；
- **笔记**：按课程/知识点聚合；
- **学习计划**：本周目标、每日提醒；
- **导出**：Markdown/PDF 学习记录（不是学位）。

### 4.13 搜索 `/search`

- 全局搜索：课程、模块、课时、知识点、术语、论文、实验；
- 支持中文/英文/缩写（如「TCP」「三次握手」「拥塞控制」）；
- 结果分组 + 高亮 + 先修提示；
- 空结果给「你可能想找」与「求助」入口。

## 5. 关键用户流程

### 5.1 新用户第一次访问

```
首页 → 我是谁（高中生/大学生/转行/研究生）
→ 选目标 → 诊断（可跳过）→ 结果页
→ 生成路径 → 第一课 → 完成第一个检查点
→ 首页出现「继续学习」
```

**成功标准**：10 分钟内完成第一个可运行实验/第一道题。

### 5.2 日常学习

```
首页 → 继续学习 / 今日复习
→ 课时（10 分钟）→ 检查点 → 实验（15 分钟）→ 练习（5 分钟）
→ 标记掌握 → 下一课
```

### 5.3 选方向

```
知识地图 → 方向节点 → 方向页（出口能力/课程/项目/论文）
→ 先修检查 → 入口课 → 方向路径
```

### 5.4 做项目

```
项目库 → 项目详情 → 读 Rubric → 建仓库/环境
→ 里程碑 1 → 提交 → 反馈 → 里程碑 2 → 最终提交 → 展示
```

### 5.5 读论文（L5）

```
论文库 → 论文导读 → 读原文 → 写 5 条笔记 + 1 个问题
→ 复现任务 → 报告 → 答辩/互评
```

## 7. 内容与状态的联动

### 7.1 掌握度模型

```
掌握度 = 测验 40% + 实验 30% + 项目 20% + 复习 10%
```

- 课程掌握 = 各模块加权；
- 方向掌握 = 课程 + Capstone + 论文；
- 能力雷达 = 知识点掌握聚合到 CS2023 领域/方向。

### 7.2 解锁规则

- 默认：先修课程「已掌握」才解锁；
- 挑战模式：通过先修测试（≥ 80）可跳过；
- 试读：允许看第一节课，但实验/项目需解锁；
- 不搞「付费解锁」的恶性卡点。

### 7.3 推荐规则

- 下一步：当前课程下一模块 → 同方向下一课 → 复习到期 → 薄弱知识点；
- 不推荐「跳级」除非诊断通过；
- 推荐理由要可解释：「因为你刚学完 B+ 树，下一课是查询优化」。

## 8. MVP 与迭代优先级

### 8.1 MVP（第一阶段，3–6 个月）

- 首页（继续学习 + 路径入口）；
- 课程库/课程页/模块页；
- 课时页（正文 + 1 种可视化 + Python 沙箱 + 练习）；
- 知识地图（静态/SVG 版，可点击）；
- 搜索；
- 进度与掌握（localStorage/后端二选一）；
- 3 个可视化组件：循环单步器、缓存模拟器、TCP 握手/抓包回放；
- **第一旗舰：S03 计算机网络**（核心课中的垂直切片）。

**不做**：诊断、项目提交、论文库、社区、AI 导师、证书。

### 8.2 P1（6–9 个月）

- 入学诊断与路径生成；
- 实验室（C/SQL/终端/网络）；
- 项目库 + Rubric + 提交；
- 复习队列/错题本；
- 能力雷达；
- 移动端优化。

### 8.3 P2（12 个月+）

- 论文库/导读/复现任务；
- AI 导师（带引用、不直接给答案）；
- 学习小组/互评；
- 教师/班级后台；
- 作品集/学习记录导出；
- 多语言。

## 9. 非功能要求

| 维度 | 要求 |
| --- | --- |
| 性能 | 首屏 < 3s（4G）；课时正文可分段加载；图/动画懒加载 |
| 可访问性 | WCAG 2.2 AA；键盘可操作；Alt 文本；对比度；reduced motion |
| 响应式 | 360px–1440px；课时三栏在 <1024px 折叠 |
| 离线 | 课时正文/笔记可离线缓存（P1） |
| 搜索 | 中文分词 + 英文/缩写；<200ms 返回 |
| 数据 | 进度本地优先，登录后云同步；导出/删除 |
| 安全 | 最小权限；实验沙箱隔离；不执行用户任意系统命令 |
| 埋点 | 课时完成、检查点、实验运行、练习、项目、复习 |
| SEO | 课程/课时静态可索引；结构化数据 |
| 版权 | 图片/论文/截图来源与许可；引用规范 |
