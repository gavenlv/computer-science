# 04 · 专业方向大纲

> 10 个方向，63 门课，424 个模块，约 2,120 课时。
> 每个方向给出：定位、入口、出口能力、课程表、模块速览、Capstone、论文清单。
>
> **选择原则**：先完成核心（或通过诊断），再选 1 个主方向深入；有余力再加 1 个辅方向，
> 辅方向只学「入口 + 2 门核心课」，不要求 Capstone。
>
> **建设原则**：10 个方向全做，但按 [02 的建设顺序](02-curriculum-map.md) 分波次推进；
> 先完成 Core v1/Core v2，网络是第一旗舰。

## D1 人工智能

**定位**：从数学直觉、经典机器学习到深度学习、大模型训练/推理与 AI 系统。
不是「调包课」，而是「能推导、能实现、能训练、能部署、能读论文」。

**入口**：M02 线代、M03 概率、M04 微积分、C04 算法；建议先修 S05、E01。

**出口能力（L4/L5）**：

- 能从零实现 MLP/CNN/Transformer/训练循环，解释反向传播与优化；
- 能完成数据清洗、特征、训练、评估、误差分析、消融；
- 能微调/对齐/部署一个开源大模型，做推理优化与评测；
- 能读懂 NeurIPS/ICML/ICLR/CVPR/ACL 论文并复现一篇。

## D2 网络通信

**定位**：从信号、协议、路由到数据中心网络与可编程数据面。既懂「为什么这样设计」，
又能抓包、测量、排障、写高性能网络程序。

**入口**：S03 网络、C02 系统编程；建议 S02、S05。

**出口能力（L4/L5）**：

- 能实现 TCP 子集/HTTP 服务器/代理/负载均衡；
- 能配置多域路由、分析 BGP/OSPF、做网络测量与排障；
- 能设计高并发接入、CDN/边缘、可编程网络方案；
- 能读懂 SIGCOMM/NSDI/ToN 论文并复现一篇。
