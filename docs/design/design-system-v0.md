# 设计系统 v0 · 阅读优先的课程界面

> 目标：让「图文并茂 + 可交互 + 可实验」的课程有一套统一的视觉与组件语言。
> 这不是品牌视觉手册，而是**课程界面的工程规范**：颜色、字号、间距、图、交互、无障碍。
>
> 适用范围：课时页、课程页、实验室、项目页、知识地图。
> 状态：v0，Phase 0 原型用；Phase 1 根据试学调整。

---

## 1. 设计原则

1. **阅读优先**：正文是主角，导航/装饰退后；一屏内不出现三个以上抢注意力的元素。
2. **一个主视觉**：每课最多一个「主图/主交互」，其余图是辅助。
3. **颜色有语义**：请求/响应/错误/内存/高亮各有固定颜色，不能只靠颜色区分。
4. **交互可单步**：所有动画/模拟必须能暂停、单步、重置。
5. **高对比、低噪音**：不用大面积渐变、玻璃拟态、霓虹光效。
6. **移动端不是缩水版**：三栏在窄屏折叠为「正文 / 实验 / 练习」三 Tab。
7. **无障碍是底线**：键盘、读屏、对比度、reduced motion、Alt 文本。

| --- | --- | --- | --- |
| `--bg` | `#f7f8fa` | `#0b1220` | 页面背景 |
| `--surface` | `#ffffff` | `#111827` | 卡片/正文容器 |
| `--surface-2` | `#f1f5f9` | `#172033` | 次级容器/代码块 |
| `--text` | `#0f172a` | `#e5e7eb` | 正文 |
| `--text-muted` | `#64748b` | `#94a3b8` | 辅助说明 |

| `--brand-strong` | `#1d4ed8` | `#3b82f6` | hover/active |

### 2.2 语义色

| Token | 值 | 用途 |
| --- | --- | --- |
| `--success` | `#16a34a` | 命中、通过、正确 |
| `--warning` | `#d97706` | 注意、边界、性能退化 |
| `--danger` | `#dc2626` | 缺失、错误、攻击 |
| `--info` | `#2563eb` | 提示、请求 |
| `--accent-teal` | `#0ea5a5` | 网络/系统 |
| `--accent-violet` | `#7c3aed` | AI/算法 |
| `--accent-amber` | `#f59e0b` | 重点/高亮 |

### 2.3 颜色语义（全站统一）

| 概念 | 颜色 | 例子 |
| --- | --- | --- |
| 请求/客户端 | 蓝 `--info` | SYN、HTTP request |
| 响应/服务端 | 绿 `--success` | SYN-ACK、200 OK |
| 错误/失败 | 红 `--danger` | 丢包、panic、攻击 |
| 内存/地址 | 灰 `--text-muted` | 指针、页表、缓存行 |
| 高亮/当前步 | 琥珀 `--accent-amber` | 当前执行行、当前状态 |
| 已访问/命中 | 青 `--accent-teal` | 缓存命中、已读节点 |

> 禁止只靠红/绿区分「命中/缺失」；必须同时有文字、图标或纹理。

## 3. 字体与排版

### 3.1 字体

```css
--font-sans: "Noto Sans SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
--font-mono: "JetBrains Mono", "SFMono-Regular", Consolas, "Liberation Mono", monospace;
```

- 中文正文用 `--font-sans`；
- 代码/终端/表头用 `--font-mono`；
- 不引入需要下载的巨大中文字体；优先系统字体。

### 3.2 字号

| Token | 大小 | 行高 | 用途 |
| --- | ---: | ---: | --- |
| `--text-xs` | 12px | 1.5 | 图注、标签 |
| `--text-sm` | 14px | 1.6 | 辅助、表格 |
| `--text-base` | 16px | 1.75 | 正文 |
| `--text-lg` | 18px | 1.7 | 导语/重点 |
| `--text-xl` | 24px | 1.4 | H3 |
| `--text-2xl` | 30px | 1.3 | H2 |
| `--text-3xl` | 40px | 1.2 | H1 |

- 正文最大宽度 `68ch`（约 720–800px）；
- 课时正文列宽 `min(100%, 760px)`；
- 段落间距 `1em`；列表间距 `0.5em`；
- 中文不使用斜体（除非英文术语）。

### 3.3 标题层级

- 每页一个 H1；
- H2 对应 10 个块中的大节；
- H3 对应步骤/子问题；
- 不跳级；不用标题做样式。

## 4. 间距与布局

### 4.1 间距

```
4 / 8 / 12 / 16 / 24 / 32 / 48 / 64
```

- 段落之间 16–24；
- 卡片内边距 20–24；
- 区块之间 48–64；
- 移动端左右边距 16–20。

### 4.2 圆角与阴影

| Token | 值 | 用途 |
| --- | ---: | --- |
| `--radius-sm` | 8px | 按钮/标签 |
| `--radius-md` | 12px | 卡片 |
| `--radius-lg` | 16px | 大容器 |
| `--shadow-sm` | `0 1px 2px rgba(15,23,42,.06)` | 卡片 |
| `--shadow-md` | `0 8px 24px rgba(15,23,42,.08)` | 弹层 |

### 4.3 课时页布局

**桌面 ≥ 1024px**：

```
┌──────────────┬──────────────────────────────┬─────────────────┐
│ 目录 220px    │ 正文 720–800px                │ 实验/术语 320px  │
│ sticky        │ 主视觉/代码/交互               │ sticky           │
└──────────────┴──────────────────────────────┴─────────────────┘
```

**平板 768–1023px**：正文 + 右侧抽屉（实验/术语）。

**移动 < 768px**：

```
[正文] [实验] [练习] [笔记]   ← 底部 Tab
```

- 图可全屏；
- 代码可横向滚动，不压缩字号；
- 表格可横向滚动或卡片化。

## 5. 视觉语法

### 5.1 图

每张图必须有：

- 标题（一句话说明「这张图在讲什么」）；
- 图注（怎么看，不是重复标题）；
- 读图任务（「注意看……」）；
- Alt 文本；
- 来源（真实截图/论文/数据）。

尺寸：

- 主视觉：16:9 或 4:3，宽度 100%；
- 辅助图：最大 720px；
- 手机端：纵向重排，不依赖 hover。

### 5.2 动画

- 只用于「状态随时间变化」或「空间关系变化」；
- 2–6 秒循环；
- 必须有暂停/单步/重置；
- 默认尊重 `prefers-reduced-motion`；
- 静态首帧/末帧可独立理解。

### 5.3 代码

- 代码块背景 `--surface-2`；
- 行号可选；
- 高亮行用琥珀左边框 + 浅色背景；
- 复制按钮；
- 可运行代码显示「运行」；
- 终端输出与代码分开；
- 错误输出用红色左边框，但不整段红字。

### 5.4 Callout

| 类型 | 用途 | 颜色 |
| --- | --- | --- |
| `why` | 为什么需要 | 蓝 |
| `warning` | 边界/坑 | 琥珀 |
| `danger` | 错误/攻击 | 红 |
| `tip` | 技巧 | 绿 |
| `history` | 历史/故事 | 灰 |

Callout 不超过 3 行；长内容回到正文。

## 6. 组件清单

### 6.1 课程组件

| 组件 | 用途 | 关键状态 |
| --- | --- | --- |
| `CourseCard` | 课程卡 | 未开始/学习中/已掌握；先修 |
| `ProgressRing` | 掌握度 | 0–100；不是滚动进度 |
| `PrereqChip` | 先修标签 | 已满足/未满足/可测试跳过 |
| `LessonShell` | 课时容器 | 桌面三栏/移动 Tab |
| `LessonTOC` | 课时目录 | 当前块高亮 |
| `BlockRenderer` | 内容块渲染 | prose/callout/visual/code/quiz/experiment |
| `Quiz` | 练习 | 未答/正确/错误/解析 |
| `GlossaryTip` | 术语 | hover/点击/跳转 |

### 6.2 可视化组件

| 组件 | 用于 | 交互 |
| --- | --- | --- |
| `LoopStepper` | 循环/递归/排序/图遍历 | 单步/播放/重置/改 n |
| `CacheSimulator` | 缓存/页表/TLB/缓冲池 | 访问地址/切换模式/调容量 |
| `TcpHandshake` | TCP/TLS/QUIC | 单步/丢包/两次握手对比 |
| `StateMachine` | 进程/TCP/编译器 | 点击事件/状态高亮 |
| `PacketInspector` | 协议头 | 展开字段/hover 解释 |
| `PcapReplay` | 抓包/排障 | 时间轴/过滤/播放 |
| `MemoryGrid` | 指针/栈帧/对象 | 拖动指针/改地址 |
| `PipelineView` | CPU 流水线 | 单步/冒险高亮 |

### 6.3 组件契约

每个可视化组件至少支持：

```ts
interface VisualProps {
  step?: number
  playing?: boolean
  reducedMotion?: boolean
  onStep?: (next: number) => void
  onReset?: () => void
}
```

要求：

- 可单步；
- 可重置；
- 有关键状态文字（不只靠颜色）；
- 移动端可操作；
- 首屏不加载重型依赖（懒加载）。

## 7. 交互状态

| 状态 | 视觉 | 文案 |
| --- | --- | --- |
| 默认 | 边框/实色 | — |
| hover | 加深/阴影 | 指针 |
| focus | 2px 外描边 `--brand` | 键盘可见 |
| active | 下沉 1px | — |
| disabled | 40% 透明度 | 说明原因 |
| loading | 骨架/进度 | 「正在运行…」 |
| error | 红色边框 + 图标 | 可读错误 + 下一步 |
| success | 绿色勾选 + 文字 | 「通过」 |

## 8. 无障碍

- WCAG 2.2 AA；
- 正文对比度 ≥ 4.5:1，大字 ≥ 3:1；
- 所有交互可键盘操作，focus 可见；
- 图有 Alt；复杂图有长描述；
- 动画可暂停/关闭；
- 不只用颜色传达状态；
- 触控目标 ≥ 44×44px；
- 支持 200% 文字缩放；
- 代码块可横向滚动，不强制换行；
- 视频/录屏有字幕。

---

## 9. 内容渲染规则

- 一个 H1；H2/H3 不跳级；
- 段落 2–5 行；长段拆；
- 列表不超过 7 项；
- 表格列不超过 6 列；移动端可横向滚动；
- 公式用 KaTeX/MathJax，提供文本 fallback；
- 代码块标注语言；可复制；
- 引用/来源用统一 `Source` 组件；
- 术语首次出现加 `GlossaryTip`。

---

## 10. 实现建议

- 用 CSS 变量 + `data-theme="light|dark"`；
- 默认跟随系统 `prefers-color-scheme`，允许手动切换；
- 不引入重型 UI 库；组件用原生 CSS；
- 可视化优先 SVG/Canvas；交互组件按需加载；
- 课时正文用 MDX/结构化 Block，不把 HTML 写死；
- 图/动画资源放 CDN/对象存储，带尺寸与占位；
- 组件 Storybook/独立 demo 页（Phase 1）。
