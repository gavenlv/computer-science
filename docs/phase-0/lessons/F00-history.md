## 1. 本课问题：计算，曾经是「人」的工作

在计算机出现之前，「计算」是一份工作。

- 一群人拿着纸笔、表格、算盘，算炮弹弹道、人口普查、天文表；
- 「computer」这个词，最早指的是**做计算的人**，不是机器；
- 一个复杂计算可能要几天、几个月，还容易出错。

人类一直在造工具来帮自己算：

```
算盘 → 手摇计算器 → 打孔卡 → 继电器 → 电子管 → 晶体管 → 集成电路 → 芯片
```

这一课只解决一个问题：

> **计算工具是怎样一步步变成「通用计算机」的？每一次跃迁，到底改变了什么？**

学完这一课，你应该能：

- 说出计算史上的几个关键跃迁，以及它们各自解决了什么问题；
- 解释「可编程」和「存储程序」为什么重要；
- 解释晶体管/集成电路为什么让计算机变小、变便宜；
- 对「摩尔定律」有正确的期待：它是观察/路线图，不是物理定律；
- 不再把「第一台计算机」当成一个简单的标准答案。

## 2. 先猜一猜

下面哪一项，是「现代计算机」最关键的思想跃迁？

- A. 用电子管代替继电器
- B. 把「程序」和「数据」一起存进内存，让机器可以执行不同程序
- C. 把计算机做得更小
- D. 用二进制代替十进制

<details>
<summary>答案与为什么</summary>

**B. 存储程序（stored program）。**

在它之前，很多机器是「专用」的：算炮弹的只能算炮弹，做统计的只能做统计。
要把一台机器用于新任务，可能要重新接线、换齿轮、改结构。

「存储程序」的思想是：

> 程序也是一组数据，可以像数据一样存进内存；
> 改变程序，不需要改变硬件，只需要换一份指令。

这让机器变成**通用**的：同一台机器，跑不同的程序，就能做不同的事。
A/C/D 都重要，但 B 是「通用计算机」的关键。

</details>

## 3. 直观模型：六次跃迁

```mermaid
flowchart LR
    A["手工计算<br/>算盘/纸笔"] --> B["机械可编程<br/>Babbage/Ada/打孔卡"]
    B --> C["机电/电子<br/>继电器/电子管"]
    C --> D["晶体管<br/>1947"]
    D --> E["集成电路<br/>1958"]
    E --> F["微处理器/个人电脑<br/>1971+"]
    F --> G["移动/云/AI<br/>2007+"]
```

| 时代 | 代表 | 解决了什么 | 局限 |
| --- | --- | --- | --- |
| 手工 | 算盘、手摇计算器 | 把计算流程化 | 慢、易错、依赖人 |
| 机械可编程 | 差分机、分析机、打孔卡 | 把「步骤」外部化 | 机械复杂、未真正建成 |
| 机电/电子 | 继电器、电子管、ENIAC | 速度从「手」到「电」 | 大、热、易坏 |
| 晶体管 | 1947 Bell Labs | 更小、更可靠、更省电 | 仍贵、仍大 |
| 集成电路 | 1958 | 把很多晶体管做在一块芯片上 | 设计/制造复杂 |
| 微处理器 | 1971 Intel 4004 | 把 CPU 做进一块芯片 | 早期性能有限 |
| 移动/云/AI | 智能手机、GPU、大模型 | 计算普及、并行加速 | 能耗、隐私、依赖 |

> 每一次跃迁，不只是「更快」，而是**让更多人能用、能做更多事**。

## 4. 拆解机制

### 4.1 算盘：把「算法」变成「手的动作」

算盘不是「自动」的，但它把计算拆成了固定的步骤：

- 表示数字（珠子）；
- 按规则移动珠子（加减乘除）；
- 记录结果。

它已经包含计算的两个核心：

- **表示**：数字怎样被编码；
- **算法**：按什么步骤操作。

但它需要人执行每一步。

### 4.2 机械可编程：Babbage、Ada、打孔卡

19 世纪，Charles Babbage 设计了差分机和分析机：

- 差分机：自动算多项式表；
- 分析机：有「存储」「运算」「控制」的雏形，被认为是最早的通用计算机设计之一。

Ada Lovelace 为分析机写了算法笔记（例如计算伯努利数），
常被称为「第一位程序员」。她还提出：机器不仅能算数，还能处理符号。

打孔卡（Hollerith，1890 年美国人口普查）让「数据」可以被机器读取，
后来成为 IBM 的基础。

**关键跃迁**：把「步骤」从人的脑子里，外化成机器可读的指令/卡片。

### 4.3 继电器与电子管：从「机械」到「电」

继电器用电磁铁控制开关，速度比机械快，但仍受机械惯性限制。
电子管用电子流控制开关，速度更快，但体积大、发热、易坏。

ENIAC（1945/46）用了约 18,000 个电子管，占地巨大。
它证明了「电子计算」的速度，但也暴露了可靠性/能耗问题。

> 这时候的机器仍然需要「重新接线/插线板」来编程，
> 离「存储程序」还有一步。

### 4.4 存储程序：von Neumann 架构

1945 年，von Neumann 起草了 EDVAC 报告，提出：

- 计算机由运算器、控制器、存储器、输入、输出组成；
- **程序和数据都放在存储器里**；
- CPU 按顺序取指令、执行。

这就是「冯·诺依曼架构」的核心。

为什么重要？

- 换任务 = 换程序，不用换硬件；
- 程序可以像数据一样被读取、修改、生成；
- 为编译器、操作系统、通用软件打开大门。

> 今天的电脑、手机、服务器，基本仍是这个架构的延伸。

### 4.5 晶体管：让计算机变小

1947 年，Bell Labs 的 Bardeen、Brattain、Shockley 发明了晶体管。
晶体管用半导体材料控制电流，替代电子管：

- 更小；
- 更可靠；
- 更省电；
- 发热更少。

这为「把更多开关塞进更小空间」铺平了路。

### 4.6 集成电路与摩尔定律

1958 年，Jack Kilby（TI）和 Robert Noyce（Fairchild）分别做出集成电路：
把多个晶体管和连线做在同一块半导体上。

1965 年，Gordon Moore 观察到：单位面积上的晶体管数量大约每年翻倍（后来改为约每两年）。
这就是「摩尔定律」。

它带来的是**指数增长**：

- 同样价格，晶体管数量指数上升；
- 计算机越来越小、越来越便宜、越来越普及；
- 但它是「观察 + 产业路线图」，不是物理定律，终会遇到功耗/散热/量子极限。

### 4.7 微处理器与个人计算

1971 年，Intel 4004 把 CPU 做进一块芯片（约 2,300 个晶体管）。
之后：

- 个人电脑（Apple II、IBM PC）；
- 图形界面、互联网；
- 移动芯片、GPU、云、AI。

今天一颗高端芯片可以有数百亿个晶体管。
从 2,300 到数百亿，是**几百万倍**的增长。

## 5. 形式化：指数增长与「通用」

### 5.1 指数增长

如果每 2 年翻倍，50 年就是 25 次翻倍：

```
2^25 ≈ 33,554,432
```

即约 3,300 万倍。
实际增长受工艺、成本、功耗限制，不一定严格每 2 年翻倍，但量级接近。

### 5.2 「通用」的代价与好处

| 机器 | 好处 | 代价 |
| --- | --- | --- |
| 专用（计算器、GPU 某单元） | 快、省电 | 只能做一件事 |
| 通用（CPU） | 什么都能跑 | 有额外开销、能效较低 |

现代系统常常「通用 + 专用」混合：CPU 做控制，GPU/NPU 做并行计算。

### 5.3 为什么历史重要

今天的设计选择，很多是历史路径依赖：

- 为什么用二进制？因为可靠地表示「开/关」比十种状态容易；
- 为什么程序和数据放在一起？因为存储程序；
- 为什么 GPU 适合 AI？因为并行；
- 为什么「兼容性」重要？因为软件生态是护城河。

## 6. 动手实验：算一算「指数」

### 环境

浏览器 Python 沙箱或本地 Python；不需要安装额外库。

### 实验 1：晶体管增长

```python
import math

start = 2_300            # Intel 4004, 1971
now = 50_000_000_000     # 现代高端芯片量级（示例）
ratio = now / start
print(f"增长倍数: {ratio:,.0f}")
print(f"约 2 的 {math.log2(ratio):.1f} 次方")
```

**思考**：50 年增长几百万倍，为什么你感觉不到「每年翻倍」？
（因为基数小的时候，翻倍也不显眼；指数在后期才爆发。）

### 实验 2：每 2 年翻倍

```python
count = 1
for year in range(1971, 2021, 2):
    count *= 2
print(count)
```

**预期**：`2^25 = 33,554,432`。
和真实增长对比：数量级接近，但真实曲线会有放缓/波动。

### 实验 3：画一条时间线（可选）

用 `matplotlib` 画晶体管数量（对数轴）：

```python
import matplotlib.pyplot as plt

years = [1971, 1978, 1982, 1989, 1993, 2000, 2010, 2020]
transistors = [2300, 5000, 29000, 275000, 3100000, 42000000, 1_000_000_000, 50_000_000_000]

plt.plot(years, transistors, marker="o")
plt.yscale("log")
plt.xlabel("year")
plt.ylabel("transistors (log)")
plt.title("Transistor count over time (approx.)")
plt.show()
```

> 数据是量级示例，不是精确历史统计；重点是「对数轴上的斜率」。

### 改一改

1. 把「每 2 年翻倍」改成「每 3 年翻倍」，50 年增长多少？
2. 查一颗你熟悉的 CPU/GPU 的晶体管数量，和 1971 年对比；
3. 用 `time` 估算：如果手工算一个 1 亿次运算，需要多久？

### 弄坏它

- 把 `now` 改成 `2_300`，增长倍数变 1；
- 把年份循环改成 `range(1971, 2021, 1)` 但每 2 年翻倍，观察「翻倍次数」和年份对不上。

### 排查

| 现象 | 可能原因 |
| --- | --- |
| 数字溢出/很大 | Python 整数没问题；其他语言注意类型 |
| 对数图看不出增长 | 忘了 `plt.yscale("log")` |
| 数据对不上 | 不同来源统计口径不同 |

## 7. 失败案例：三个关于「计算机史」的误解

### 误解 1：「第一台计算机就是 ENIAC」

「第一台」取决于定义：

- 机械/机电/电子？
- 可编程/通用/存储程序？
- 公开/保密？

Z3（1941，德国）、Colossus（1943，英国，破译）、ENIAC（1945/46，美国）各有资格。
更准确的说法是：**它们都是通向现代计算机的关键里程碑**。

### 误解 2：「摩尔定律是物理定律，会永远持续」

摩尔定律是**观察 + 产业路线图**，不是自然规律。
它依赖工艺、成本、功耗、散热；近年来已经明显放缓。
今天更多靠「专用加速器/封装/并行」而不是单纯缩小晶体管。

### 误解 3：「新的一定更快」

新芯片可能主频更低但核心更多；新架构可能更适合某些负载。
性能取决于** workload + 架构 + 软件**，不是单纯看年份。

## 8. 三个常见误区

1. **以为** 计算机一开始就是「通用」的；
   **实际** 早期多是专用/需重新接线；
   **因为** 「存储程序」是后来的关键跃迁。

2. **以为** 计算机史就是「硬件越来越快」；
   **实际** 还有编程、操作系统、网络、软件生态的跃迁；
   **因为** 通用计算机的价值在「可编程 + 生态」。

3. **以为** 摩尔定律会一直持续；
   **实际** 已放缓，靠新架构/封装/专用芯片继续提升；
   **因为** 物理/功耗/成本限制。

## 9. 检索练习

### Q1

「存储程序」为什么重要？

<details>
<summary>答案</summary>

程序和数据都存进内存，换任务只需换程序，不用改硬件。
这让机器变成通用计算机，也为编译器/操作系统/软件生态打开大门。
</details>

### Q2

晶体管相比电子管，主要优势是什么？

<details>
<summary>答案</summary>

更小、更可靠、更省电、发热更少，能集成更多开关。
</details>

### Q3

摩尔定律是什么？它是物理定律吗？

<details>
<summary>答案</summary>

摩尔定律是观察到「单位面积晶体管数量约每两年翻倍」的产业趋势/路线图，不是物理定律。
它会受功耗、散热、成本、量子极限限制，已经放缓。
</details>

### Q4

为什么现代系统常用「CPU + GPU/NPU」？

<details>
<summary>答案</summary>

CPU 通用、擅长控制/分支；GPU/NPU 擅长并行/矩阵计算。
混合架构兼顾通用性与能效。
</details>

### Q5（迁移）

如果让你给一个初中生讲「计算机史」，你会选哪三个跃迁？为什么？

<details>
<summary>参考答案</summary>

例如：

1. 可编程（Babbage/Ada/打孔卡）：机器能按步骤执行；
2. 存储程序（von Neumann）：换程序不换硬件，通用计算机；
3. 晶体管/集成电路：变小、变便宜、普及。

理由：这三次分别解决了「可编程」「通用」「可普及」。
</details>
