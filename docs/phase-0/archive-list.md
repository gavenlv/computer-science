## 2. 为什么归档

### 2.1 核心路径要收敛

新体系的核心是：

```
Python → C → 算法/系统/网络/数据库 → 一个方向
```

不在核心阶段并行教 JS/TS、Java、C++、Go。
语言是载体，不是目的；需要时在方向/项目里学。

### 2.2 前端是「方向/项目」，不是核心必修

Web 前端很重要，但它属于「软件工程/全栈」方向，不是所有计算机人的必修。
把 24 条前端内容放入 X01 选修，避免核心膨胀。

### 2.3 专家运行时/竞赛是「选修/研究」

JIT/GC 源码、竞赛算法对少数人很有价值，但不适合作为所有人的核心课。
它们更适合：

- 作为 S06/C04 的延伸阅读；
- 作为 X04/X05 选修；
- 作为论文/项目方向。

## 4. 未来可重新引入的条件

- 核心 v1 完成，有稳定的学习者群体；
- 有人明确需要 Web/Java/C++/竞赛/运行时；
- 有外部作者/审校，不占用核心生产时间；
- 能按新 10 块标准重写，而不是直接搬旧大纲。

> 归档不是「否定」，是「排期」。
> 先把核心做深，再考虑长尾选修。
