## 4. 每节课的 Definition of Done

- [ ] 10 个块齐全（问题/先猜/模型/机制/形式化/实验/失败/误区/练习/连接）；
- [ ] 1 个主视觉或交互 Spec；
- [ ] 1 个可运行实验 + 预期输出 + 改一改 + 弄坏它 + 排查；
- [ ] 3–5 道检索题 + 解析；
- [ ] 1 个真实系统/论文/文档链接；
- [ ] 来源与版权记录；
- [ ] 至少 1 次自审/外部审校；
- [ ] 移动端可读、图有 Alt、交互可键盘操作；
- [ ] 录入站点（Phase 1 后）。

> 没有「实验 + 练习」的课时，不算完成；只能算草稿。

## 5. 生产节奏

| 模式 | 周产 | 月产 | 说明 |
| --- | ---: | ---: | --- |
| 标准课 | 2–3 节 | 10–13 节 | 正文 + 1 图/截图 + 1 沙箱 + 3 题 |
| 旗舰课 | 1 节/1–2 周 | 2–4 节 | 定制交互 + 真实实验 |
| 混合 | 2 节标准 + 1 节旗舰/2 周 | 10–15 节 | 推荐 |

> 第一年 100–130 节 ≈ 每周 2–3 节，持续 10–12 个月。
> 不追求「日更」；追求「每节都能学、能跑、能测」。
